Bem-vindo ao sistema de comparação Nota X Romaneio!

Este sistema foi desenvolvido com o objetivo de agilizar o processo de comparação dos dados da nota fiscal com os dos romaneios, utilizando os SKUs dos produtos e suas respectivas quantidades.

Como utilizar o sistema?

O sistema possui duas áreas principais: uma destinada à nota fiscal e outra aos romaneios. Insira cada informação em sua respectiva área. Não se preocupe com a quantidade de campos! É possível criar até 10.000 campos no total entre as duas áreas. Basta informar a quantidade desejada.

Outras funções:

No canto inferior da página, também estão disponíveis alguns botões, cada um com uma função específica. É possível limpar os campos preenchidos, salvar as informações e carregar os dados salvos. Logo em seguida, encontra-se o botão responsável por verificar se os dados informados na nota estão de acordo com os dados presentes nos romaneios.

Caso seja identificada alguma divergência, o sistema informará qual código apresenta o erro e em qual campo a informação está divergente, facilitando a identificação e correção do problema.
